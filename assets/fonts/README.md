# Self-hosted web fonts

Served from rubenhm.org itself so pages make no request to Google Fonts.
Declared in `_brand.yml` (`source: file`). All are licensed under the SIL Open
Font License 1.1 (https://openfontlicense.org): Merriweather, Mate, Source
Sans 3, JetBrains Mono, Esteban. Downloaded (latin + latin-ext, woff2) from
google-webfonts-helper (https://gwfh.mranftl.com).
