# talks

Previous presentations, served at <https://rubenhm.org/talks/>. Each talk is
a git submodule pinned to a commit (usually its last); `index.html` lists them.

Add a talk: `git submodule add -b main https://github.com/rubenhm/<repo>.git <folder>`
(prefer `https://` URLs, which GitHub Pages documents for submodules),
then add an entry to `index.html`.
